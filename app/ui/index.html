    Tests & Simulation

    Charge test

    Reads charging power once a second for 30 seconds and looks for drops. Plug in the charger and cable you want to check, with the battery below 80%.

    Drive write test

    Writes a 256 MB temporary file to a folder you pick on a USB drive, times it, then deletes it. Nothing else on the drive is touched.

    Port watch

    Watches each port for 10 seconds and flags a cable that keeps dropping and reconnecting. Plug and unplug while it runs if you want to test a loose connection.

    Both-ends test

    Checks each end of a cable in both plug positions. Two results that disagree can show a faulty end, while one position that fails can show a dirty contact.

    Self-check

    Checks that this report is internally consistent. It does not test the cable.
